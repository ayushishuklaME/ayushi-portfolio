---

## Run Locally

```bash
git clone https://github.com/ayushishuklaMe/ayushi-portfolio.git
cd ayushi-portfolio
npm install
npm run dev
```

---

## Deploy

```bash
npm run deploy
```

Deploys to GitHub Pages via `gh-pages` package.
